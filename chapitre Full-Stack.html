Créez une page web en codant un élément html. N'oubliez pas que nous pouvons créer un html élément en codant "html"et "/html".

body ser a structuré une page web

L' élément head en HTML est un conteneur pour les informations relatives à une page web, comme son titre. Il se place avant la balise `body`.

!doctype html permet de définir la version de HTML utilisée

Pour inclure un fichier CSS dans un fichier HTML, on utilise l'élément link. L'attribut href indique le chemin vers le fichier CSS. L'attribut rel indique que le fichier est une ressource liée à la page HTML. la balise link est auto-fermant qui se place à l'intérieur de l'élément head.

petit exercice

Si nous voulons sélectionner un ou plusieurs éléments, nous pouvons définir un classattribut pour les éléments précis que nous voulons modifier. Dans la feuille de style, nous pouvons définir une nouvelle règle de classe avec un class .suivi du nom de la classe. Comme ici avec `class` .gray-element.

Pour définir une classe comme sélecteur en CSS, ajoutez un point suivi du nom de la classe. Dans ce cas, il s'agit de « class » .gray-element.
